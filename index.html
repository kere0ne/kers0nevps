Built like a real VPS, minus the sysadmin work

Docker isolation

Every server is its own container with hard memory and CPU limits. A crash loop in one bot can never starve another.

Self-healing

Containers restart on crash and come back with the node on reboot. The watchdog never clocks out.

Live console

Stream stdout and stderr straight from the panel. Start, stop, restart, or attach without ever opening SSH.

Secrets stay server-side

Bot tokens and API keys are environment variables stored on the host and injected at runtime. They never reach the browser or your git history.

FAQ

What happens when my bot crashes?

The watchdog detects the exit and restarts the container automatically. If it crash-loops more than five times in ten minutes, it is stopped and flagged in the panel so you can fix the bug without burning restart cycles.

Where do my bot tokens live?

Server-side only. You set them as environment variables in the panel and they are injected into the container at runtime, stored on the host. They are never sent back to the browser.

Can I run anything besides Discord bots?

If it fits in a container and respects your resource limits, yes. Webhooks, APIs, cron jobs, all fair game.

How is this different from a normal VPS?

Same isolation and control, without managing the OS, firewall, or process manager. The panel handles deployment, logs, and restarts so you only think about your code.

Do I get a free trial?

Sign up and deploy your first server without a card. Billing is handled per node, outside the panel.
