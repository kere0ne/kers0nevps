D

Docker isolation

Every server is its own container with hard memory and CPU limits. A crash loop in one bot can never starve another.

W

Self-healing 24/7

Containers restart on crash and come back with the node on reboot. The watchdog never clocks out.

C

Live console

Stream stdout and stderr straight from the panel. Start, stop, restart, or attach without ever opening SSH.

S

P

FAQ

Is it actually free?

Every plan is free during open beta, no card required. If paid plans ever arrive, existing beta servers keep their resources.

What happens when my bot crashes?

The watchdog detects the exit and restarts the container automatically. If it crash-loops repeatedly, it is stopped and flagged in the panel so you can fix the bug.

Where do my bot tokens live?

Server-side only. You set them as environment variables in the panel and they are injected at runtime. They are never sent back to the browser.

Can I run anything besides Discord bots?

Yes. Webhooks, APIs, static sites, cron jobs. If it fits in a container and respects your limits, it runs.

Do you support Node and Python?

Both, plus static sites. Entry point is index.js, main.py, or your index.html.
