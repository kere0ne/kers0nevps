FAQ

Is it really free?

Yes. Every account gets every plan automatically. There is no billing anywhere in the product.

What can I host?

Python, Node.js and bash scripts. Discord bots are the star, but any long-running script works.

Where does my bot token go?

Straight onto the hosting node in a server-side env file. The API never returns it, not even to you — leave the field empty and the saved token is reused.

What happens when my bot crashes?

The watchdog notices within ten seconds and respawns it. Each recovery is logged so you can see why.
