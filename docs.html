Features Plans Open panel

Developer API

Base URL: your node's address, for example https://your-node.example.com. Authenticate every request with a personal access token created in the panel, sent as a bearer header.

Authentication

Create a token in the panel under API tokens, then send it on every call:

Authorization: Bearer kv_your_token_here

List servers

GET/v1/servers
curl -s https://your-node.example.com/v1/servers \ -H "Authorization: Bearer kv_..." # { "servers": [ { "id": "srv7f3a91", "name": "luacrypt-bot", # "runtime": "python", "plan": "basic", "status": "online", # "createdAt": "..." } ] }

Create a server

POST/v1/servers
curl -s -X POST https://your-node.example.com/v1/servers \ -H "Authorization: Bearer kv_..." \ -H "Content-Type: application/json" \ -d '{"name":"my-bot","runtime":"python","plan":"basic","exposePort":false}' # { "server": { "id": "srv7f3a91", "status": "offline" } } # runtime: node | python | static plan: mini | basic | pro

Server actions

POST/v1/servers/:id/actions
curl -s -X POST https://your-node.example.com/v1/servers/srv7f3a91/actions \ -H "Authorization: Bearer kv_..." \ -H "Content-Type: application/json" \ -d '{"type":"start"}' # type: start | stop | restart returns { "action": "start", "ok": true }

Logs

GET/v1/servers/:id/logs
curl -s https://your-node.example.com/v1/servers/srv7f3a91/logs \ -H "Authorization: Bearer kv_..." # { "logs": [ "...", "..." ] } last 200 lines

Terminate a server

DEL/v1/servers/:id
curl -s -X DELETE https://your-node.example.com/v1/servers/srv7f3a91 \ -H "Authorization: Bearer kv_..." # { "ok": true } container and files are removed permanently

Typical flow

# 1. create POST /v1/servers # 2. upload zip POST /api/servers/:id/upload (multipart, same token) # 3. set secrets POST /api/servers/:id/env {"key":"DISCORD_TOKEN","value":"..."} # 4. start POST /v1/servers/:id/actions {"type":"start"} # 5. watch GET /v1/servers/:id/logs
